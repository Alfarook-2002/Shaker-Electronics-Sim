Shaker Electronics Simulator

Interactive Circuit Simulator with Mobile UI

About This Project

Shaker Electronics Simulator is a responsive, touch-friendly electronic circuit simulator designed for both desktop and mobile devices.

Features & Highlights

  • Responsive layout optimized for smartphones, tablets, and desktops.
  • Real-time schematic analysis and SPICE simulation.
  • Custom components: Silicon, Germanium, and Ideal Diode models.
  • Mobile navigation drawer, quick-access toolbar, and touch gestures.
  • Zero installations required — runs directly in modern web browsers.
